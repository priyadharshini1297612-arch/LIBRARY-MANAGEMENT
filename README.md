# AI Library Management System

## Features

- Student Registration
- Admin Login
- Book Management
- Borrow Books
- Return Books
- Fine Calculation
- AI Book Recommendation
- AI Chatbot
- Payment Screenshot Upload
- Email Reminders
- PDF Reports
- Analytics
- CSV Storage

## Installation

pip install -r requirements.txt

## Run

python main.py

## Email Reminder

Configure Gmail App Password inside email_service.py

## Report

Generate report using menu option.
